# Oto II ─ 光と音のあそび場

カメラとマイクだけで遊ぶ、光と音のゲームと楽器のコレクション。
コントローラーはあなたの手と体と声です。毎晩 深夜2時に、ゲームと楽器が少しずつ増えていきます。

**▶ https://apaapaapaapaapa2006-source.github.io/oto-2/**

すべての作品はブラウザ内で完結します。映像や音声が外部に送信されることはありません。

---

## 構成

各作品は依存ゼロの自己完結した HTML ファイル 1 枚で、リポジトリ直下のフォルダに置かれます（`shinkai/index.html` など）。ビルド工程はありません。`main` への push で GitHub Actions が Pages へ自動デプロイします。

`index.html` がギャラリーです。カードは `<!-- GAME-CARDS-START -->` / `<!-- INSTRUMENT-CARDS-START -->` のマーカーの間に追記します。テンプレートは `index.html` 内のコメントにあります。
