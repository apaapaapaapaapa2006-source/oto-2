# Oto II — 2台でひとつの画面（CAMERA FX試作）

あなたのWebアプリの描画を横2台分に広げ、親のiPhoneに左半分、子のiPhoneに右半分を表示する試作です。写真用のDual iPhone Displayとは別のアプリです。

**対応はCAMERA FXと接続テスト画像のみ。183作品すべてへの対応はまだ行っていません。iPhone実機の動作保証は未確認です。**

## 仕組み

親だけがカメラ入力・手の検出・WebGLエフェクト・音を実行します。親のCanvasは横幅2台分で描画し、CSSで左半分だけ表示します。そのCanvasの映像をWebRTCで子へ送り、子は右半分を表示します。子はカメラ・マイクを使用せず、音も出しません。作品の設定ボタンは親に残します。右端末からの操作転送は未実装です。

同じ機種・同じ向き・同じSafariバーの状態で使ってください。異なる端末の実寸、画面比率、ベゼルを補正する機能はありません。音と左画面は親で直接動き、右画面は映像の圧縮・転送・復号分だけ遅れます。完全な同時表示ではありません。

## Macで見る

1. ターミナルで `cd ` と入力し、このフォルダーをドラッグしてReturn。
2. `python3 server.py` を実行。
3. `http://localhost:8001` を開く。
4. 「テスト画像で接続する」を開き、右上の「2台表示」から「左画面を開始・共有リンクを作る」。
5. リンクを別のブラウザーウィンドウで開き「右画面を開始」。
6. 2画面を同じ大きさにして横へ並べ、左右の文字・横線・動く黄色い丸を確認。
7. 終了は親の「終了」、サーバー停止はターミナルでControl+C。

通常のPython標準ライブラリだけで起動します。既定ポートは8001。別のポートなら `PORT=8080 python3 server.py`。

## iPhoneで試すためのRender公開

**現在の oto-2.vercel.app は変更していません。以下はこの試作を別URLで試験公開する手順です。** iPhoneからMacのHTTPローカルIPへアクセスする方法ではカメラを利用できないため、HTTPSのURLを使います。Vercelに静的HTMLを置くだけでは、今回のPython接続サーバーは動きません。

1. RenderでNew → Web Serviceを選び、GitHubの `apaapaapaapaapa2006-source/oto-2` を接続します。
2. Branchを `codex/dual-iphone-camera-fx` にします。mainへマージする必要はありません。
3. Root Directoryを `experiments/oto-dual` にします。
4. RuntimeはPython 3、Build Commandは `python -m py_compile server.py`、Start Commandは `python server.py`、Health Check Pathは `/health`。
5. インスタンスは1台。試験用プランの料金を確認してDeployします。
6. 表示された `https://...onrender.com` を両iPhoneで開きます。

Renderのサーバーは接続情報だけを仲介します。映像・音声をアップロードするAPIはありません。WebRTCには外部STUN/TURNサーバーを設定していないため、まず同じ通常Wi-Fiで使います。ゲストWi-Fi、端末間通信を禁止するWi-Fi、VPN、Safariの接続候補制限などによっては同じWi-Fiでもつながらない場合があります。インターネット越しの接続は対応範囲外です。

無料サービスが休止中なら、最初に公開URLを開いて起動を待ってください。再起動・再デプロイで接続用の部屋は消えます。リンクは再作成してください。

Render公式資料：https://render.com/docs/web-services ／ https://render.com/docs/free

## 実機確認の順番

1. 両iPhoneを同じ向きに並べます。最初はカメラなしのテスト画像を選びます。
2. 親の「2台表示」からリンクを作り、「リンクを共有・コピー」で子へ渡します。
3. 子のSafariでリンクを開き「右画面を開始」。親が左、子が右です。
4. 両方でパネルを隠します。横線と中央の色の境目が合うか、黄色い丸が左から右へ渡るかを確認します。
5. それぞれを回転させた場合の表示と、10分間の継続表示を確認します。形が歪む場合は両方を同じ向き・同じSafari表示状態に戻します。
6. 次に親でCAMERA FXを開き、STARTを押してカメラを許可します。
7. 親で映像が出てから「2台表示」を押し、新しいリンクで子を接続します。子はカメラを許可する必要がありません。
8. 親のFX切り替え、AUTO、前後カメラ切り替えを試し、両側が同じ映像の左右になっていることを確認します。
9. Safariを裏に回して戻す・Wi-Fi切断を試します。復帰しない場合は親で新しいリンクを作り、子で開き直します。自動再接続は実装していません。

リンクは1回の受信接続専用です。他人へ公開しないでください。リンクを知る端末が先に接続すると、その端末へ映像が送られます。部屋作成の際にカメラ映像を外部へ配信することを理解した上で、自分の子端末だけに共有してください。

## 他の作品へ広げるとき

各作品の描画Canvasと、動画・Canvas・DOMの重ね合わせを確認して対応します。CAMERA FXは完成映像が1枚のCanvasにあるため最初の対象にしています。カメラのvideo要素と透明なCanvasを重ねる作品は、それらを1枚に合成してから配信する必要があります。単純にURLを入れるだけで全作品が動く汎用ブラウザーではありません。
