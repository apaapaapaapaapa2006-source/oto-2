エフェクト

Effects
🕰TOKI 今と数秒前が一枚に同居するスリットスキャン。手のあるところだけが「今」で、離れるほど過去の自分が映る。握れば時間が止まり、止まった時間の中を探せる。 EFFECT ・ 時間の層 🎛CAMERA FX カメラ映像をその場で加工するフィルター台。MATRIX・ASCII・GLITCH・THERMAL・KALEIDO・PIXEL を切り替えて、自分の姿が別物に変わる。 EFFECT ・ カメラフィルター 🖐HAND//GLITCH 手の動きに反応して映像が裂けるグリッチエフェクト。通常・グリッチ強・ミニマルの3モードで、走査線とパネルのノイズ量が変わる。 EFFECT ・ 手のグリッチ 🖨AMITEN カメラ映像をその場で網点に分解して刷る印刷機。左右の手がそれぞれインキの版を引っぱるので、動かすと見当がずれて色が裂ける。両手を合わせると一枚刷り上がる。 EFFECT ・ 網点の刷り台 💧MINAMO カメラ映像が水の底に沈むエフェクト。本物の波動方程式を解いているので、波は端で跳ね返り、ぶつかって干渉する。指先で水をつつけ、じっとしていれば凪いで顔が戻る。 EFFECT ・ 水面ごし 🛣HAKUCHU カメラを街へ向けると、空もビルも白く飛んで、退色したスキャンの色に沈むエフェクト。輪郭は製図のインクでなぞられ、構造のあるところだけを探して手描きの注釈と矢印が書き込まれていく。長押しで元の映像。 EFFECT ・ 白昼の図解 🌀NAGORI 画面が二度と描き直されないエフェクト。動画コーデックと同じやり方で動きを測り、その向きに絵を引きずるだけなので、動くほど自分が背景へ溶けていく。手のひらを止めると、そこだけ今に拭き戻る。 EFFECT ・ 引きずる
