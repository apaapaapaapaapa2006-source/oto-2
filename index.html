楽器

Instruments
🪗FUIGO 両手のあいだに蛇腹がかかる一方向のふいご。広げても音は鳴らず空気が溜まるだけで、寄せて縮めているあいだだけリードが鳴って溜めた分が減っていく。長いフレーズは吸うところから組み立てる。 INSTRUMENT ・ 蛇腹に風を溜める 🎚KYOMEI 部屋の物音が八本の弦を励起する共鳴器。机を叩く、指を鳴らす、ハミングする。カメラは体ではなく光を見ていて、レンズを手でおおうと音が暗く短くなる。 INSTRUMENT ・ 部屋を鳴らす 🎐IKI マイクに息を吹きこんで鳴らす笛。息はそのまま管の中の空気になり、手の高さが音の高さ、手の開き具合が音色になる。強く吹けば実際の笛のように一オクターブ跳ねる。 INSTRUMENT ・ 息の笛 🎋SHOU 十本の指が、そのまま十本の竹になる笙。指を曲げるとその管が鳴り、曲げた深さがそのまま音の太さになる。手を高く掲げるほど息が強く、両手を離すほど簧が唸る。調子は双調・黄鐘・盤渉。 INSTRUMENT ・ 指で吹く 🎻KOKYU 右手が弓、左手が棹になる擦弦楽器。動かしている間だけ鳴り、止めれば音は消える。左手を上げるほど弦の振動する長さが実際に短くなり、その長さの比がそのまま音程になる。 INSTRUMENT ・ 擦弦 🥁TSUZUMI 打つ手と締める手でひとつになる小鼓。真ん中を打てばポン、端はチ。もう一方の手を握るほど調べ緒が締まって音が上がる。 INSTRUMENT ・ 小鼓 🔔KANE 霧の中に吊られた五つの梵鐘。手を速く振り抜けば撞け、鳴っている鐘に掌をかざせば高い倍音から順に消えていく。倍音は本物の鐘の比で二本ずつずらしてあるので唸りが立ち、その唸りがそのまま輪になって見える。 INSTRUMENT ・ 梵鐘 💧SUIKIN 手をひらくと指先から雫が落ち、地面に埋めた甕に入ったものだけが鳴る。鳴らすのは手ではなく重力なので、落ちるまでの間がそのまま楽器になる。にぎれば掌に溜まり、ひらけば一度に落ちて和音になる。 INSTRUMENT ・ 地の底で鳴る ⛏HIROI マイクが直前の六秒をずっと録っていて、その六秒が地層になって横たわる。両手はその上の採取針で、触れた場所の音が粒になって舞い上がる。握れば地層が凍り、その一瞬をいつまでも弾いていられる。 INSTRUMENT ・ 音の地層 🪢KYOWA 左半分の手が「基」、右半分の手が「応」。二つの音の比がそのままリサージュ図形になり、比が濁っているあいだ図形は唸りの速さで回りつづける。純正な比に寄せると回るのをやめて一本の線に凍り、倍音が重なって二つの音が一つに融ける。合わせるのは目ではなく耳。 INSTRUMENT ・ 耳で合わせる 🪕MUKKURI 音の高さを一度も変えない楽器。弁は決まった一つの高さで鳴りつづけ、変わるのは口のなかの空洞だけ。口をひらけば下の共鳴が、横にひろげれば上の共鳴が上がり、どの倍音が選ばれているかが口のなかに見える。手から弁へは紐がかかっていて、振れば弾かれる。 INSTRUMENT ・ 口琴

エフェクト

Effects
🌀AWASEKAGAMI カメラ映像が一フレームごとに自分自身へ映り込みつづける合わせ鏡。いまのあなたが入ってこられるのは画面のふちと手のひらに開いた穴だけで、そのあいだにあるものは全部、何十回も色を回されたあなたの過去。 EFFECT ・ 合わせ鏡の奥 🕰TOKI 今と数秒前が一枚に同居するスリットスキャン。手のあるところだけが「今」で、離れるほど過去の自分が映る。握れば時間が止まり、止まった時間の中を探せる。 EFFECT ・ 時間の層 🎛CAMERA FX カメラ映像をその場で加工するフィルター台。MATRIX・ASCII・GLITCH・THERMAL・KALEIDO・PIXEL を切り替えて、自分の姿が別物に変わる。 EFFECT ・ カメラフィルター 🖐HAND//GLITCH 手の動きに反応して映像が裂けるグリッチエフェクト。通常・グリッチ強・ミニマルの3モードで、走査線とパネルのノイズ量が変わる。 EFFECT ・ 手のグリッチ 🖨AMITEN カメラ映像をその場で網点に分解して刷る印刷機。左右の手がそれぞれインキの版を引っぱるので、動かすと見当がずれて色が裂ける。両手を合わせると一枚刷り上がる。 EFFECT ・ 網点の刷り台 💧MINAMO カメラ映像が水の底に沈むエフェクト。本物の波動方程式を解いているので、波は端で跳ね返り、ぶつかって干渉する。指先で水をつつけ、じっとしていれば凪いで顔が戻る。 EFFECT ・ 水面ごし 🛣HAKUCHU カメラを街へ向けると、空もビルも白く飛んで、退色したスキャンの色に沈むエフェクト。輪郭は製図のインクでなぞられ、構造のあるところだけを探して手描きの注釈と矢印が書き込まれていく。長押しで元の映像。 EFFECT ・ 白昼の図解 🌀NAGORI 画面が二度と描き直されないエフェクト。動画コーデックと同じやり方で動きを測り、その向きに絵を引きずるだけなので、動くほど自分が背景へ溶けていく。手のひらを止めると、そこだけ今に拭き戻る。 EFFECT ・ 引きずる ⏳SUNA 体が砂になって崩れ落ちるエフェクト。落ちた砂は本物の粒として積もり、あなたの肩や頭にも溜まっていく。腕を振ればその山は崩れて散る。砂の色は、カメラが見たあなたの色。 EFFECT ・ 砂になる 🪟HIBI カメラの見た一瞬が、窓ガラスとしてそこに凍りつくエフェクト。指先で突くと罅が枝分かれしながら走り、囲まれた欠片が割れて落ちる。落ちた穴からだけ、今のあなたが動いて見える。 EFFECT ・ 罅の入った窓 🌌OMOMI 手が質量になり、その重さで光が曲がるエフェクト。景色は輪に巻きついて二重になる。重力は光を遅らせるので、輪に映るあなたは少し前のあなた。手を振ると輪はあとから振り返す。 EFFECT ・ 光を曲げて遅らせる 🧵NUIME カメラに映るものが布の上に一針ずつ刺繍されていくエフェクト。映像は出てこない、出てくるのは布と糸だけ。糸の向きは絵の形そのものに沿い、色は32色の糸箱から選ばれる。じっとしていれば肖像が仕上がる。 EFFECT ・ 布に縫われる 🕳UTSURO 手のひらに穴がのるエフェクト。陰影もふちの光も影もないので、目はそれを球として読めず世界に開いた穴として読む。傾ければ転がり、指を曲げれば閉じこめられる。そしてそれは通り過ぎた場所のディテールを食べて大きくなる。 EFFECT ・ 手のひらの虚ろ 🎭IROKAGE 赤・緑・青の三灯があなたを照らし、体が遮った影に色がつくエフェクト。赤だけを遮った影はシアン、緑ならマゼンタ、青ならイエロー。三灯はあなたのシルエットの外側に吊られ、自分の体で自分の光を遮る。 EFFECT ・ 色のついた影 🌫KEMURI カメラに映るものが煙そのものになる。本物の流体計算なので煙は渦を巻き、手を払えばその速さがそのまま風になって残りつづける。じっとしていれば顔が結び、動けばほどける。香・渦・墨の三つ。 EFFECT ・ 流体 🗿UKIBORI カメラの色を全部捨て、明るさの傾きだけを面の向きに変えて石を彫るエフェクト。映るのはあなたではなく光のかたち。手のひらがそのまま光源になり、動かせば影が振れ、握れば光が硬く尖る。石膏・銅・漆。 EFFECT ・ 陰影だけ 🧲JIBA カメラに映るものが一面の砂鉄になって紙に積もる。暗いところほど密に、一粒ずつが両手の作る磁場の向きに首を振ってそろう。手を近づければ二極のあいだに砂鉄の橋がかかる。 EFFECT ・ 砂鉄と磁場 ✂️KIRIE カメラ映像を明るさで切り分けて、色紙を重ねた切り絵にするエフェクト。紙と紙のあいだには本当に隙間があり、手を開くと層が離れて影が落ち、手を動かすと視差でずれる。 EFFECT ・ 切り絵の層 📼ROKUGA カメラ映像を本物のコンポジット信号に変えて、わざと下手に復調して戻すエフェクト。色は滲み輪郭にドットクロールが這う。動いたところほどテープが擦り切れ、そこだけ色が死んで画が欠けていく。 EFFECT ・ 擦り切れたテープ 🌧AMAMADO カメラ映像が曇った窓の外になる。粒はひとつずつ本物のレンズで、中だけ景色が広く逆さに映る。手のひらで拭えば晴れ、重くなった粒は流れ落ちて筋を残す。 EFFECT ・ 雨の窓 ✍️MASUME 映った人だけが升目に分かれ、一マスずつ違う描線で塗られる。どのマスがどの線かは位置で決まっていて変わらない。升目の大きさはスライダーで、ペンは七色から。背景は白紙のまま。 EFFECT ・ 升目の線描 🗺CHIKEI カメラに映るものの明るさをそのまま標高として読み、本物の等高線を引いて一枚の地形図にする。顔は鼻を頂上にした山になり標高点が打たれる。手を上げると水位が上がって低い所から沈む。地形図・海図・断面。 EFFECT ・ 等高線 🎨NIJIMI 映るものが、白い紙に置いた透明水彩になる。絵の具は重なるほど濃くなるだけなので明るい所には何も塗られず紙が残り、乾き際の縁には顔料が溜まって輪郭が濃くなる。手は水を含んだ筆で、通った所は紙が濡れて滲む。顔料六種と、色相・彩度・濃さ・にじみ・縁だまり・階調・粒状のつまみ。 EFFECT ・ 透明水彩 🪲TAMAMUSHI カメラに映った人の輪郭の中だけが玉虫色に光るエフェクト。色はパレットではなく本物の薄膜干渉の計算で、つまみは膜の厚さ（ナノメートル）そのもの。画面にさわると輪郭が波打つ。 EFFECT ・ 玉虫色の膜 🧫MADARA カメラは絵ではなく反応の速さを配っていて、明るい所は斑に暗い所は迷路に育つ。フィルターではないので顔をそむけても模様は勝手に成長を続ける。指先から撒き、握った手で拭える。 EFFECT ・ 反応拡散 📺KISEN カメラ映像を一本の電子ビームが走査して描くブラウン管。画面は一度も消されないので燐光が焼きついて残る。明るさは塗るものではなくビームの速さそのもので、部屋の音が輝線を揺らし、手をかざした所だけ暴れて白熱する。 EFFECT ・ 消えない輝線 🧶NISHIKI カメラ映像が縦糸と横糸にほどけて、本物の織り組織で織り直される。縦糸は縦の色を、横糸は横の色を運び、交点ごとにどちらが上かが決まる。平織・綾織・繻子で布の目がまるごと変わり、手を握れば布をつかんで引っぱれる。 EFFECT ・ 織り直す 🫗SHITATARI 明るいところだけを明るさの順に並べ替える。並べ替えた結果をもう一度並べ替えつづけるので、じっとしているほど絵は溶けて長いリボンになって垂れていく。動けばそこだけ今のカメラが戻る。手の高さが溶ける量、手のひらの開きが一筋の長さ、手のまわりだけ流れが逆さになる。 EFFECT ・ 並べ替えて垂らす 🌀SUMINAGASHI 水面に墨を落として櫛で梳く本物の墨流し。落ちた墨は先の墨と混ざらず、ただ外へ押し広げるだけ。拡散が一度も起きないので何十回梳いても濁らず、髪より細い筋まで伸びていく。色はカメラが見たものから採る。手をひらけば櫛、握れば指先から墨が落ちる。 EFFECT ・ 墨流し
